# Ask (end user)

Climbers and coaches do not run `junior_aie` modules.

From a checkout of JuniorLLM:

```bash
PYTHONPATH=. python rails/linux/juniorctl.py ask "is flagstaff usually dry in late summer?"
```

Public seeds only (RFL, Flagstaff OSMP, North Table, Xanadu, JuniorHall indoor, covenant).
Gym programs stay in this app under `/stonefield/programs` with `gym_internal`.
