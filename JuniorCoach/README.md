# JuniorCoach (Modern Touch for JuniorClimbs)

Intelligent coaching layer for bouldering/climbing gyms.

## Features
- Health & Physical Therapy timelines
- Training timelines & periodization
- Competition / Tournament timelines (games x tourneys)
- Personalized recommendations via BitNet-Intel / AGI_SDK
- Communication pipelines (email, media, marketing automation)

## Integration
- Pulls from JuniorClimbs member/infrastructure data
- Uses JuniorAGI_SDK for intelligent planning
- Future: Swift app integration for coaches and athletes
