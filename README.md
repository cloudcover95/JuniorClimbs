# JuniorClimbs (Public Open Source Example)

**Important Note on Scope**

This repository contains example/reference implementations for a climbing gym operations system.

- Public OSS code is designed to be portable and run in varied environments.
- In-house JuniorCloud LLC production systems may have additional integrations, different hardware assumptions, private networking, and custom extensions not present in this public repo.
- Users should treat this as a starting point / reference architecture rather than a direct copy of any production deployment.

## Current Public Features

- Employee terminal with privacy-friendly customer info (hard copy mode)
- Safety zones on optical dash + agent interface
- Calendar/events (yoga, crossfit, classes, camps)
- Marketing campaigns
- Second Brain finance ledger (Web3-style immutable commits)
- Portable CSV/Excel for maintenance and finance reporting
- Admin reporting endpoints
- Recommendation/forecasting hooks (ready for BitNet-powered optimization)

All code remains additive and aligned with the broader sovereign JuniorCloud LLC public architecture (BitNet, manifolds, routed execution).
