# JuniorClimbs

**Production POS + Member Access System**

- Employee POS with keychain/wafer barcode swipe confirmation
- QR-based first-time waiver + auto-onboarding (zero employee data entry)
- Real-time account balance for merch, snacks, drinks
- Renewal alerts and member status audit
- Admin web dashboard for operations, marketing, and communication

Built on JuniorCloud LLC sovereign architecture (BitNet, manifolds, routed execution).
